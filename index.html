1. Introduction

Welcome to C/C++ Compiler: Learn & Code ("the App"), developed and maintained by Shahbaz Studios ("we", "us", or "our").

We are firmly committed to protecting your privacy. This Privacy Policy explains how our application handles information when you use our mobile software on your Android device.

Quick Summary: We do not collect, sell, or track any personal information. You do not need to register an account. All your project code stays on your device unless you choose to compile and run it.

2. Information Collection and Use

Our application does not require any account creation or registration. We do not gather or store any personally identifiable information (PII), including but not limited to:

  • Your name, address, or phone number
  • Your email address or social media profiles
  • Your precise or approximate GPS location
  • Your biometric information or device hardware identifiers (IMEI/MAC)

3. Code Compilation & Execution Data

When you write C or C++ code in the editor and press the RUN button:

  • Transmission: The source code text and standard input (stdin) that you entered are transmitted securely via encrypted HTTPS to our cloud compiler sandbox API (Wandbox GCC service).
  • Processing: The remote server compiles and executes the program using GCC (GNU Compiler Collection) in an isolated sandbox environment.
  • Return: The terminal output (stdout), syntax errors, or warnings are returned to your device screen.
  • Non-Retention: Your source code is strictly processed in memory for execution and is not saved, stored, or shared with any third parties or marketing services.

4. Local Storage & Drafts

All your projects, custom draft code, and user preferences (such as code editor font size, daylight/midnight theme mode, and virtual laptop keyboard preference) are stored strictly locally on your device using private internal storage (cpp_projects.json and preferences).

This data never leaves your device unless you explicitly export or delete it yourself.

5. Device Permissions

The App requests only the minimal permissions required to function:

  • android.permission.INTERNET: Required solely to communicate with the online GCC cloud compiler API to execute code and retrieve terminal output.

We do not request permissions for Camera, Microphone, Location, Contacts, SMS, or External Storage.

6. Third-Party Services

The application interacts only with the following external services:

  • Google Play Services: Used by the Android operating system to manage app updates and installation integrity. Google's privacy policy can be viewed at Google Privacy Policy.
  • Wandbox Cloud Compilation Engine: An open-source, community-trusted sandboxed code execution backend used exclusively for compiling C/C++ code via HTTPS.

7. Children's Privacy

Our App is an educational coding tool suitable for learners, students, and developers of all ages. We do not knowingly collect or solicit any personal information from children under the age of 13. If you believe any data has inadvertently been provided, please contact us and we will promptly address it.
